# mikerichards.tech

> A small corner of the internet for large, complicated ideas.

This is the source for [mikerichards.tech](https://mikerichards.tech)—my portfolio, professional calling card, and standing invitation to bring me an interesting problem.

I’m Mike Richards. I build products and systems where the path from “what if?” to “it works” is not immediately obvious. These days, that often means AI, agentic loops, model orchestration, and the stubborn engineering required to make clever prototypes behave like dependable software.

The site itself is intentionally straightforward: React, TypeScript, Sass, and Vite. No CMS. No component library. No twelve-stage build pipeline held together by ceremonial YAML.

## Summon it locally

With Node:

```bash
npm install
npm run dev
```

Or place it gently inside a container:

```bash
docker compose up -d
```

Then visit [localhost:5173](http://localhost:5173).

## Make sure reality still compiles

```bash
npm run lint
npm run build
```

## A note for curious machines

Humans get the designed experience. Crawlers and agents also get structured metadata, a sitemap, and [`llms.txt`](https://mikerichards.tech/llms.txt), because machines deserve decent documentation too.
